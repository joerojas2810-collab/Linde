## Prompt exacto

Supporting reference: existing wooden fence and objects in this pixel RPG. Create ONE new fence-parts sheet, transparent background, exactly 4 evenly spaced columns x 1 row. Column0 a north-south VERTICAL wooden fence section viewed top-down oblique, same posts, two rails, brown wood and golden lit caps as the reference horizontal fence. Column1 an L-CORNER connecting north and east with one shared corner post, same materials. Column2 a T-JUNCTION connecting north/east/west with one shared post. Column3 a FOUR-WAY CROSS joining north/south/east/west with one shared central post. No barrel, no chest, no workbench, no other objects; those images are style support only. Use a single consistent tiny pixel size, hard edges, no antialias or blur, 2-3 tones per wood color, simple dark outline. Generous transparent margins, no shadow separate from object. Make every part the same physical scale as the reference fence, in concept 48x48 native canvases, with anchors at ground contact. Do not make an illustration or show a landscape. No text or labels. Preserve consistent rail endpoints so pieces can be aligned in a 16-pixel tile grid.
