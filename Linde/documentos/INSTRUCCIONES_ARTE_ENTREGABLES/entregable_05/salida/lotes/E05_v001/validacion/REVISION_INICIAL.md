# Revisión del primer sublote

La casa96 todavía no cubre la huella lógica128x112; la separación de capas es una prueba exacta de fuente, no una casa modular acabada. Extremos de las vallas pendientes de calibración.

Se inspeccionaron los PNG compuestos, no solo las generaciones grandes. El render de esta escena muestra dichos PNG en Godot; no es la integración ni una prueba de las reglas del juego. No hay aceptación visual del usuario registrada.
